## n8n Workflow

The RateXAI Scoring API is orchestrated via an n8n workflow. Below is the complete workflow definition.

### Workflow Nodes

The pipeline consists of the following nodes:

1. **API Entry1** — Webhook endpoint receiving POST requests with header auth
2. **Validate Input** — Validates required fields (`type`, `project`, `project_url`) and constructs the job object
3. **Route by Type** — Routes to Post-TGE or Pre-TGE prompt preparation based on `type`
4. **Prepare Post-TGE Prompt** / **Prepare Pre-TGE Prompt** — Sets system and user prompts
5. **Message a model** / **Message a model1** — Calls Claude claude-sonnet-4-5-20250929 with web search enabled
6. **Parse & Format** — Extracts JSON from model response, formats by `output_format`
7. **Success Response1** — Returns 200 with formatted report
8. **Error Handler1** — Classifies errors (400/422/500/504)
9. **Error Response1** / **Error Response2** — Returns appropriate error responses
